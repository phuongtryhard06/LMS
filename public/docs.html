Tài Liệu Tích Hợp API LMS ICTU

Hệ thống proxy kết nối tự động với backend LMS apps.ictu.edu.vn:9087.

POST /api/process-headers

Phân tích chuỗi Request Headers copy từ F12 DevTools để lấy student_id, class_id và tokens.

curl -X POST http://localhost:3000/api/process-headers \ -H "Content-Type: application/json" \ -d '{"headersText": "..."}'
POST /api/classes

Lấy danh sách các lớp học phần và năm học / kỳ học của sinh viên.

POST /api/class-details

Lấy tên lớp và thông tin chi tiết giảng viên, học phần.

POST /api/course-plan

Lấy kế hoạch tuần học theo môn học.

POST /api/test-results

Lấy danh sách bài kiểm tra và điểm tổng kết theo tuần học.

POST /api/test-details

Bóc tách toàn bộ câu hỏi, danh sách đáp án lựa chọn và chi tiết bài kiểm tra.
